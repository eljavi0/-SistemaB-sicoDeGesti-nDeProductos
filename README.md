#   SistemaBásicoDeGestiónDeProductos

Este proyecto es un sistema básico de gestión de productos que permite a un administrador registrar, consultar, actualizar y eliminar productos dentro de una base de datos.

El desarrollo se realiza utilizando la metodología Scrum, organizando las funcionalidades en historias de usuario y sprints.

## Funcionalidades

- Registrar productos
- Ver lista de productos
- Consultar información detallada de un producto
- Actualizar productos
- Eliminar productos
- Filtrar productos

## Historias de Usuario

- HU1: Como administrador quiero registrar productos para guardarlos en el sistema
- HU2: Como administrador quiero ver productos para conocer cuáles existen
- HU3: Como administrador quiero seleccionar un producto para ver su información
- HU4: Como administrador quiero ver información detallada del producto
- HU5: Como administrador quiero actualizar productos
- HU6: Como administrador quiero eliminar productos
- HU7: Como administrador quiero filtrar productos

## Tecnologías

- C#
- Windows Forms
- .NET

## Metodología

El proyecto se desarrolla bajo la metodología Scrum, organizando el trabajo en sprints.

Cada funcionalidad se implementa a partir de historias de usuario definidas en el backlog del proyecto.
